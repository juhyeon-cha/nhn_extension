# 업무 도우미

Chrome·Edge 확장 프로그램으로, 구내식당 메뉴 조회·알림, NHN Harmony 퍼플 타임 일괄 조정, 공유설비 회의실 예약표 개선 기능을 제공합니다.

## 주요 기능

- **구내식당 메뉴**: Payco 메뉴 페이지 연동, 메뉴 알림 설정
- **두레이 연동**: 설정한 봇/URL로 메뉴 알림 전송
- **회의실 예약표**: 정시 세로 구분선, 예약 구간별 색상, 빈 회의실 검색·발견 알림과 일정 간격 새로고침
- **퍼플 타임 일괄 조정**: NHN Harmony 퍼플 타임 페이지에서 일괄 조정 (컨텍스트 메뉴)

## 기술 스택

- Manifest V3
- Vanilla JS (ES Modules)
- Chrome Extension APIs: `storage`, `alarms`, `contextMenus`, `scripting`, `notifications`

## 프로젝트 구조

```text
nhn_extension/
├── manifest.json          # 확장 프로그램 설정
├── background.js          # Service Worker (메뉴 알람, 메시지 라우팅)
├── content.js             # Payco 메뉴 페이지용 콘텐츠 스크립트
├── content-purple-time.js # 퍼플 타임 페이지용 콘텐츠 스크립트
├── content-room.js        # 회의실 페이지 표시와 반복 조회
├── content-room.css       # 회의실 구분선·색상·검색 패널
├── room/model.js          # 30분 칸 해석과 빈 시간대 판정
├── room/notifications.js  # 회의실 데스크톱 알림 처리
├── tests/                 # 빈 시간대 판정·회의실 알림 핵심 경로 검증
├── popup/
│   ├── frontend/          # 팝업 UI (index.html, popup.js)
│   └── message.js         # 팝업 관련 메시지/설정 처리
├── options/
│   └── frontend/          # 옵션 페이지 (index.html, app.js, app.css)
├── menu-alarm/            # 메뉴 알람 로직 (listener, utils, message)
└── assets/                # 아이콘 등 정적 리소스
```

## 설치 및 로드 (개발용)

1. 저장소 클론 후 프로젝트 루트로 이동
2. Chrome에서 `chrome://extensions/` 접속
3. **개발자 모드** 켜기
4. **압축 해제된 확장 프로그램을 로드합니다** 클릭 후 이 프로젝트 폴더 선택

## 사용 조건

- **구내식당 메뉴**: `https://menu.payco.com/*` 에서 동작
- **퍼플 타임**: `*://nharmony.nhncorp.com/user/hrms/odm/attend/purpleTime.nhn*` 페이지에서 컨텍스트 메뉴 사용

## 회의실 예약표 사용

1. 확장을 새로고침한 뒤 `https://pt.nhncorp.com/room` 페이지를 새로고침합니다.
2. 왼쪽 달력에서 날짜를 선택하고 회의실 유형·층을 설정합니다.
3. 예약표 위 **빈 회의실 찾기**에서 시작·종료 시간을 08:00~22:00 사이의 30분 단위 목록에서 선택하고 조회 간격(기본 5분)을 입력합니다.
4. **현재 표에서 찾기**는 이미 표시된 표에서 검색합니다. **반복 조회 시작**은 현재 표를 검색한 뒤 지정한 간격으로 페이지 전체를 새로고침하고 다시 검색합니다.
5. **중단**을 누르거나 페이지의 다른 영역을 클릭·키보드로 조작하면 반복 조회가 중단됩니다. 검색 조건 변경과 회의실 페이지 이탈도 조회를 중단합니다.

요청 시간대 전체가 `예약 가능`인 회의실만 표시합니다. 예약 불가, 모르는 상태, 불완전한 시간 칸은 빈자리로 간주하지 않습니다. 검색 범위는 현재 표에 로드된 회의실 중 B1(지하 1층)을 제외한 회의실이며, 결과는 예약을 보장하지 않습니다.

**반복 조회 시작** 시 이미 빈 회의실이 있으면 데스크톱 알림을 보냅니다. 이후에는 직전 조회보다 새로 예약 가능해진 회의실만 알리며, 같은 결과로 새로고침해도 반복해서 알리지 않습니다. 예약됐다가 다시 빈 회의실은 다시 알립니다. **현재 표에서 찾기**는 결과만 표시합니다. 알림에는 선택 날짜·시간과 회의실 이름이 표시됩니다.

확장 프로그램에 `notifications` 권한이 추가되었습니다. 확장과 공유설비 페이지를 새로고침하고 알림 권한을 허용해 주세요. 브라우저 알림이 차단되거나 알림 생성에 실패하면 이유를 표시하고 반복 조회를 중단합니다. OS 알림 설정이나 집중 모드는 별도로 알림 표시를 막을 수 있습니다.

정시 구분선은 셀 크기를 바꾸지 않고 그립니다. 칸 위쪽 색상은 예약 구간을, 아래쪽 원래 색상은 기존 예약 상태를 보여줍니다. 제공된 HTML에는 회의 ID가 없으므로 같은 회의실에서 같은 예약자가 연속된 칸을 하나의 회의로 묶습니다. 같은 사람이 연달아 예약한 별도 회의는 구분할 수 없습니다.

반복 조회는 탭을 열어 둔 동안 동작합니다. 새로고침 후 사이트가 선택 날짜·유형·층을 유지하면 검색을 재개하며, 조건이 달라지면 중단 이유를 표시합니다. 사이트가 초기화한 필터를 자동으로 다시 선택하지 않습니다. 로그인 만료나 표 로딩 실패는 빈 회의실 결과로 표시하지 않습니다. 브라우저 절전·백그라운드 제한으로 조회가 지연될 수 있습니다.

## 설정

- 확장 프로그램 아이콘 클릭 → 팝업에서 메뉴 알림 on/off, 두레이 봇/URL 등 설정
- 아이콘 우클릭 → **옵션** 으로 상세 설정 페이지 이동

## 개발

- 수정 후 `chrome://extensions/` 에서 해당 확장의 **새로고침** 버튼으로 반영
- `background.js` 변경 시 Service Worker 재시작 필요 (확장 새로고침)
- 회의실 시간 판정·알림 테스트: `node --test tests/*.test.cjs` (추가 패키지 불필요)
- 회의실 기능은 제공된 HTML 구조를 재현한 로컬 DOM에서 검증했습니다. 알림은 브라우저 API 대역으로 요청 내용과 실패 처리를 검증했습니다. 실제 사내 페이지의 레이아웃·서버 데이터 갱신과 OS 알림 표시는 별도 확인이 필요합니다.
